# Data card: OpenStreetMap extract for Pennsylvania via Geofabrik (`osm_network`)

**Contributes.** The street network the routing engine (R5 through r5py,
M3) walks: every way with a `highway` tag inside the routing extent, with
the nodes that give it shape, plus the turn restrictions among them. It
contributes nothing until the routing spike runs on it (EP-13 onward); no
metric reads it, nothing published is derived from it yet, and the basemap's
roads come from TIGER/Line, not from here. It is the **first Bucket B
source of the real pipeline** ([ADR-0003](../../roadmap/adr/0003-license-buckets-odbl.md)):
every table that carries a value computed over this network, travel-time
matrices first, is ODbL by derivation, and so is every combined export that
contains one.

**Provider and file.** OpenStreetMap contributors, extracted and published
by Geofabrik GmbH as the Pennsylvania region file. The **dated** extract
`pennsylvania-260831.osm.pbf` from
`https://download.geofabrik.de/north-america/us/`, 345,912,530 bytes,
Geofabrik's MD5 `a779d2ef14c8addce6eac207ab9cd851` (its sibling `.md5`
file, fetched through the same guarded path and stored beside the data as
`pennsylvania-260831.osm.pbf.md5`). Never the `-latest` file, whose bytes
change every day. Geofabrik defines no sub-region for Pennsylvania, so the
state file is what exists. A PBF is not an archive: the download path caps
it at 1 GiB and never opens it as a zip.

**Vintage.** OpenStreetMap data as of the extract's replication timestamp,
2026-08-31T20:21:20Z (the file's own header; generated by Geofabrik on
2026-09-01, `osmium/1.16.0`, sorted `Type_then_ID`, header bounding box
81.378 W to 74.688 W, 38.921 N to 42.516 N). Pinned snapshot
**`2026-09-03`** (`phillysim.pipeline.SNAPSHOT_IDS["osm_network"]`; snapshot
IDs are per source since EP-12, so the five sources acquired on 2026-09-02
keep their date). A controlled refresh is a new dated extract pinned by an
amendment to [ADR-0008](../../roadmap/adr/0008-routing-toolchain-pins.md),
a new entry here, and a changelog line; it moves the routing results'
methods version (ADR-0006).

**Terms and license.** Open Database License (ODbL) 1.0; the data are
© OpenStreetMap contributors. The Geofabrik region page in force
(`https://download.geofabrik.de/north-america/us/pennsylvania.html`) is
archived beside the snapshot as `terms.html` and checked in its visible text
for the phrases "created by OpenStreetMap Contributors" and "License: ODbL";
a change stops acquisition. **Bucket B** (ODbL, share-alike): outputs that
contain values computed over this network carry the ODbL label and the
notice "© OpenStreetMap contributors"; rendered maps are Produced Works
(attribution notice only). Nothing derived from it is published in the M3
spike ([docs/DATA-LICENSES.md](../DATA-LICENSES.md)). Citation:
"OpenStreetMap contributors, Pennsylvania extract pennsylvania-260831.osm.pbf
via Geofabrik (ODbL 1.0)".

**Coverage and filter.** Stored as delivered: the whole state, verifiable
against the provider's MD5. The county filter is the **clip** the `network`
stage writes (`phillysim.adapters.osm.clip`): the county bounds
(`adapters.base.COUNTY_BOUNDS`) buffered by **5 km** in the analysis CRS and
expressed in WGS 84 (ADR-0007, ADR-0008): longitude 75.360257 W to
74.880953 W, latitude 39.804412 N to 40.195375 N. Every way with at least
one node inside that box is kept with **all** of its nodes (the
way-complete strategy R5 needs), every `type=restriction` relation whose
members are all kept is kept, tags and metadata are kept as delivered, and
the objects are written in the source file's order with the box in the
header. The pinned clip, measured on 2026-09-03: **5,803,119 nodes**
(5,782,922 inside the box; the rest belong to ways that cross it),
**921,869 ways** (224,252 with a `highway` tag), **3,693 relations**,
49,968,756 bytes, from a state file of 45,125,372 nodes, 4,903,283 ways,
and 55,814 relations; about three minutes on the pinned Windows machine.
The clip's node and way counts must fall inside a recorded band (4 to 8
million nodes, 0.6 to 1.3 million ways) or the stage fails: a count outside
the band means the extract or the box changed. ADR-0008's recorded
fallback, feeding R5 the whole state file, remains available if the clip
ever cannot be built.

**CRS.** OpenStreetMap coordinates are WGS 84 (EPSG:4326) and stay so: R5
reads the PBF directly. The clip box is computed in the analysis CRS
EPSG:26918 (metres) and expressed back in WGS 84 for the clip.

**Where it lands.** `intermediate/network/pennsylvania-260831-philadelphia-5km.osm.pbf`
(the clip; Bucket B by derivation, provenance the `osm_network` snapshot the
`network` stage names as its input) and the counts above in
`intermediate/network.json`. The state extract itself never leaves the raw
zone.

**Known limits.**
- OpenStreetMap is volunteered data: completeness and tagging vary by
  neighbourhood, and a missing crossing, a mis-tagged footway, or a barrier
  node changes walking times locally. The M3 hand check (EP-15) is the first
  measurement of that.
- The extract is a single day's state; a later extract differs in ways that
  have nothing to do with access, so every result reproduces from the pinned
  file and a refresh is a methods-version change.
- The 5 km buffer covers walking access to any stop a Philadelphia trip can
  use at the pinned walking speeds; a transit trip that leaves the buffer
  (Regional Rail to the suburbs) is routed over the buffer's edge only as far
  as the feed's stops carry it.
- Nodes outside the box that belong to a kept way are present with their
  coordinates, so a way is never truncated; a way that only *passes near*
  the box without a node inside it is absent.

**Claims matrix.** Nothing in this card or in any output derived from the
network states or implies simulation, prediction, or clinical guidance
(C-1 through C-4 in [docs/CLAIMS.md](../CLAIMS.md)): a travel time computed
over it is a descriptive measurement under stated assumptions (walking
speed, pinned dates, the feed), and the ODbL label names its source. No
accessibility statement rests on it until M5 publishes the routing outputs
with their method cards.

**Checks that bind it.** Source contract (`phillysim.adapters.osm`: the
delivered file's MD5 equals the provider's sidecar, the header parses with
a bounding box enclosing the county bounds and the expected sorting,
Bucket B), the pinned MD5 and the sidecar check at acquisition (a mismatch
quarantines with kind `digest`), the terms phrases, the clip's own
contract (`osm.check_clip`, enforced by the `network` stage: a readable
PBF whose header carries the box, counts inside the bands, every node
inside the box or referenced by a kept way, `highway` ways present), and
the snapshot manifest (`phillysim verify`).
